\# Universal AI Client 🚀



Лёгкий десктопный клиент для работы с LLM-моделями через OpenAI-совместимый API.



\### Возможности:

\- Пресеты провайдеров: TokenClub, OpenRouter, OpenAI, ProxyAPI и свой Base URL

\- Сохранение истории переписок и настроек

\- Поддержка горячих клавиш (Ctrl+C, Ctrl+V, Ctrl+A) на любой раскладке клавиатуры

\- Чистый тёмный интерфейс на CustomTkinter



\### Запуск из исходников:

```bash

pip install -r requirements.txt

python app.py
