# Universal AI Client 🚀

Лёгкий десктопный клиент для работы с LLM-моделями через API на базе CustomTkinter.

### Возможности:
- Пресеты: TokenClub, OpenRouter, OpenAI, ProxyAPI и свой Base URL
- Сохранение истории переписок и настроек
- Горячие клавиши (Ctrl+C, Ctrl+V, Ctrl+A) на любой раскладке клавиатуры
- Тёмный интерфейс
